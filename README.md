# 🌹 Flowers Shop - বাংলাদেশের জন্য ই-কমার্স ওয়েবসাইট

"Bringing Nature's Finest to Your Doorstep." এ আমরা সুন্দর ফুলের তোড়া এবং সাজানো ফুলের ব্যবস্থা করি।

## 🎯 প্রকল্পের বৈশিষ্ট্য

- ✅ পণ্য তালিকা ও বিস্তারিত
- ✅ উন্নত সার্চ এবং ফিল্টার
- ✅ শপিং কার্ট এবং চেকআউট
- ✅ ইউজার অ্যাকাউন্ট এবং প্রোফাইল
- ✅ অর্ডার ট্র্যাকিং
- ✅ রিভিউ এবং রেটিং সিস্টেম
- ✅ বাংলা ভাষা সমর্থন
- ✅ নিরাপদ পেমেন্ট গেটওয়ে ইন্টিগ্রেশন

## 🛠️ প্রযুক্তি স্ট্যাক

### Frontend
- **React.js** - ইউজার ইন্টারফেস
- **React Router** - পেজ নেভিগেশন
- **Axios** - API কল
- **Redux/Context API** - স্টেট ম্যানেজমেন্ট
- **Tailwind CSS** - স্টাইলিং

### Backend
- **Node.js** - রানটাইম
- **Express.js** - ওয়েব ফ্রেমওয়ার্ক
- **MongoDB** - ডেটাবেস
- **JWT** - অথেন্টিকেশন
- **Multer** - ফাইল আপলোড

### অতিরিক্ত
- **Stripe/bKash API** - পেমেন্ট
- **Nodemailer** - ইমেইল সেবা
- **Docker** - কন্টেইনারাইজেশন

## 🚀 শুরু করা

### প্রয়োজনীয় সফটওয়্যার
- Node.js (v14+)
- MongoDB
- npm বা yarn

### ইনস্টলেশন

#### ব্যাকএন্ড সেটআপ
```bash
cd server
npm install
npm run dev
```

#### ফ্রন্টএন্ড সেটআপ
```bash
cd client
npm install
npm start
```
